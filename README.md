# Python - Funções e Modularização

## 📖 Objetivo

Desenvolver exercícios acadêmicos utilizando funções e modularização para promover a reutilização de código e a organização de programas em Python.

## 📂 Conteúdo

O repositório contém exercícios sobre:

- Criação de funções;
- Passagem de parâmetros;
- Retorno de valores;
- Modularização de programas.

## 💻 Tecnologias

- Python 3

## ▶️ Como executar

1. Instale o Python 3 em seu computador.
2. Clone este repositório ou faça o download dos arquivos.
3. Execute o arquivo desejado pelo terminal:

```bash
python nome_do_arquivo.py
```
